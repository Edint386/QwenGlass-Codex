description: 当用户想在千问眼镜上查看或操作 Codex Desktop 的代码任务、继续某个桌面任务、看实时进度、计划、文件改动、切换任务、给 Codex 发一句话时使用。Use when：打开 Codex、看代码任务、看看桌面版 Codex、继续那个任务、切换代码任务、看看 Codex 在做什么、Codex 的计划、改了哪些文件、给 Codex 发句话。Do NOT use：普通聊天、查天气、星座运势、成语接龙、与 Codex Desktop 无关的编码问答。
---

# 规则

1. 这个技能进入后，页面、语音草稿、翻页、切换任务和发送都由连接器服务处理。不要调用 UI 页面渲染工具，也不要调用其他工具。
2. 不要复述、总结或朗读代码；不要猜任务内容。用户没明确要求时，不要主动播报。
3. 如果页面没有自动出现，只播报一句：“Codex 连接器没有打开页面，请确认电脑上的桥接程序在运行。”
4. 发送到 Codex 的内容必须由用户在眼镜页面上单击确认；不要替用户自动发送。
5. 不在眼镜上展示 token、密钥、完整命令、终端输出或大段代码。

# 使用

- 前滑/后滑：回复翻页；运行中切换时间流页。
- 单击：打开菜单；菜单里可切换任务、看进度/回复、计划与改动、快捷回复、字号。
- 双击：退出技能。
- 语音说“切换任务”“计划”“取消”等由服务处理；其他话进入草稿，需再单击发送。
